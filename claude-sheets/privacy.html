Privacy Policy — Claude Sheets

Claude Sheets is a private tool used by one person to let their own AI assistant read and edit their own Google Sheets. This policy explains what Google user data it accesses and how that data is handled.

What Google data is accessed

Claude Sheets requests two Google permissions:

  • https://www.googleapis.com/auth/spreadsheets — see, edit, create and delete the owner's Google Sheets spreadsheets.
  • https://www.googleapis.com/auth/script.projects.readonly — view the owner's Google Apps Script projects. Read-only: it cannot change a script.

The tool itself only reads cells, writes cells, adds rows and reads script code. It contains no code to delete spreadsheets or tabs, to share them, or to change a script.

How the data is used

Cells are read and written on demand, solely to carry out the owner's own requests about their own spreadsheets. Data is not used for advertising, profiling or analytics, and it is not used for any purpose beyond fulfilling the owner's direct request.

Who the data is shared with

The tool runs on the owner's own computer. Cell contents it reads are passed to the owner's AI assistant, Claude by Anthropic, under the owner's own Anthropic account, so the assistant can answer the owner's request. Data is not sold, rented or shared with anyone else. There are no advertisers and no analytics providers.

How the data is stored

The tool keeps two things on the owner's own computer:

  • An OAuth token, used solely to authenticate to Google.
  • A log of each write: the time, the spreadsheet, the range, and the cell values before and after, so any change can be undone. The log sits in the owner's own cloud file storage.

Google API Services User Data Policy

Claude Sheets' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions, which immediately ends Claude Sheets' access.
